# Как обновлять код Project Iz на GitHub

Репозиторий: https://github.com/makanpornop-hub/project-iz — закрытый.
Рабочая папка: `C:\Project Iz`.

## Один раз настроить GitHub Desktop

1. Установите GitHub Desktop с https://desktop.github.com/ и войдите в аккаунт `makanpornop-hub`.
2. Выберите **File → Add local repository**.
3. Укажите уже существующую папку `C:\Project Iz` и нажмите **Add repository**.

В этой папке уже настроен Git и подключён репозиторий. Добавляется существующий проект; повторная загрузка копии из GitHub в эту папку не нужна.

## После каждого изменения

1. Измените и сохраните код в `C:\Project Iz`.
2. Проверьте результат на локальном сайте.
3. В GitHub Desktop откройте **Changes** и просмотрите изменённые файлы.
4. В **Summary** кратко опишите изменение, например «Добавил фильтр клиентов».
5. Нажмите **Commit to main**, затем **Push origin**.

Commit сохраняет версию на компьютере. Push origin отправляет её на GitHub.
Если кнопки Push origin нет, а сверху показано Fetch origin, проверьте, что изменения уже сохранены и отправлены.

Когда над кодом работают с другого компьютера, перед началом работы нажмите **Fetch origin**, затем **Pull origin**, если эта кнопка появилась. При конфликте остановитесь и разберите его перед отправкой.

Пароли, `.env`, клиентские документы и база исключены из Git. Файлы зависимостей и локальные служебные папки также не отправляются. Обычно отправляются исходники и настройки без секретов.

Обновление GitHub само по себе не публикует изменение на сервере. После запуска CRM онлайн обновление сервера будет отдельным шагом по `deploy/README.md`. Автоматическая публикация ещё не настроена.

Можно поручить отправку помощнику: «Проверь изменения Project Iz и отправь код на GitHub».
